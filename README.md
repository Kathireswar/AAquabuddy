# AquaBuddy — Windows 11 Water Reminder Desktop Companion

AquaBuddy is a transparent Windows 11 desktop companion built with Electron, React, TypeScript, and Vite.

## Quick Start
1. `npm install`
2. `npm run lint`
3. `npm test`
4. `npm run dev`
5. `npm run dist:win` (builds the Windows NSIS installer in `release/1.0.0/`)
